# AutoShorts: Privacy Policy
_Last updated: November 2026_

AutoShorts is a private tool that publishes the owner's own videos to the owner's own TikTok and YouTube accounts.

- **What we access:** for the owner's accounts only, the basic profile (to confirm the account), permission to upload
  videos, and the owner's own video statistics (views, likes, comments, shares), used to decide which videos to make next.
- **What we don't do:** we don't collect data about viewers or other users, we don't sell or share any data, and we
  don't use data for advertising.
- **Storage:** access tokens are stored encrypted as secrets in a private GitHub repository. Statistics are stored as
  aggregate numbers in the same private repository.
- **Deletion:** the owner can revoke access at any time in TikTok or Google account settings. All stored data is deleted
  on request to yashwanthkumarkotla@gmail.com.
